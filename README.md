# Hyperliquid Smart Screener & Terminal (Hyperscreener)

Автономний аналітичний скрінер та торговий термінал для безстрокових контрактів (Perpetuals) біржі **Hyperliquid**, створений з використанням **TradingView Lightweight Charts** та алгоритмів **Smart Money Concepts (SMC)** і класичного цінового аналізу (Price Action).

---

## 📸 Можливості

1. **Прямі дані з Hyperliquid без затримок:**
   - Повний список активних контрактів (230+ монет) зі швидкістю оновлення мілісекунди.
   - Свічки `1m`, `5m`, `15m`, `1h`, `4h`, `1D`.
   - Інформація про **Open Interest (відкритий інтерес)**, ставки фінансування (**Funding Rates**) та об'єм за 24 години.

2. **Графік TradingView Lightweight Charts:**
   - Швидкий Canvas-рендеринг на 60 FPS у стильному темному дизайні.
   - Автоматичне нанесення рівнів підтримки та опору з підрахунком дотиків (`x2`, `x3`, `x8`...).
   - Відображення бичачих та ведмежих зон дисбалансу **FVG (Fair Value Gaps)**.
   - Маркери точок входу та свіпів ліквідності на свічках.

3. **Алгоритмічний Screener Engine:**
   - **Каскади рівнів (Breakout cascades):** виявлення кількох щільно розташованих рівнів із підтисканням ціни.
   - **Хибні пробої / Зняття ліквідності (Liquidity Sweeps):** детекція проколу рівня тінню свічки та повернення тіла назад.
   - **Fair Value Gaps (FVG):** детекція 3-свічкових імбалансів та відстеження їх пом'якшення (*unmitigated / mitigated*).
   - **Аналіз структури ринку:** визначення поточного тренду (BULLISH, BEARISH, CONSOLIDATING) за послідовністю HH/HL або LH/LL.

4. **Інтерфейс терміналу (точно як на скріншоті):**
   - Сайдбар рівнів із точною дистанцією у відсотках (`Опір +0.42%`, `Підтримка -0.41%`).
   - Перемикання фільтрів формацій: *Без формацій*, *Пробій (каскад)*, *Відскік / хибний пробій*, *FVG*, *Наклонки*, *Всі формації*.
   - Модальний скрінер зі списком найгарячіших монет Hyperliquid з активними формаціями.
   - Спливаючий Alert Toast у правому нижньому кутку при виявленні сигналу.
